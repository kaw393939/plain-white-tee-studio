## A useful review conversation

Start with one question: **Which real situation should this shirt help someone prepare for, and what should the page help them decide?**

Once that is clear, review the [three territories](/strategy/ideas) and choose which hypothesis deserves a prototype. A preference is useful; the reason makes it actionable.
