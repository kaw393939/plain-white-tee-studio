# From research to a reviewable brand

The review site is ready to organize the discussion. The storefront identity still needs a deliberate choice and a prototype. Follow the sequence below; record actual outcomes as the work happens.

## 1. Choose a situation

Compare the [three idea territories](/strategy/ideas) against the [competitive examples](/research/landscape). Select one primary audience need and one contrasting secondary need. Write small cards with the situation, desired meaning, concern, and decision the page should help someone make.

**Reviewable output:** two short cards, clearly marked as hypotheses. Seek a few relevant conversations before treating a need as validated; a small convenience sample still cannot establish broad demand.

## 2. Agree a brief

Choose a working name, one-sentence promise, one primary archetype, and three voice traits. Add one example line of copy and a prediction about how the page should affect the intended visitor. An archetype describes the brand’s recurring character, not the customer’s personality.

**Reviewable output:** a compact brief with a reason for the audience choice. Check that the promise avoids unsupported material, fit, environmental, or performance claims.

## 3. Compare two visual approaches

Create a modernist hero and a postmodernist hero. Keep product, headline, support, facts, and action identical. Inspect actual work from primary museum or designer sources before naming it as an influence; a caption alone does not establish that a composition was viewed.

For each treatment, annotate two or three decisions, the intended audience effect, and one risk. Modernism and postmodernism are broader than “plain” and “colorful”; both directions must be legible and useful.

**Reviewable output:** two live previews or matching screenshots at desktop and narrow widths, with reference URLs and dates. Choose or adjust the direction using a visible detail that helps the visitor.

## 4. Build one coherent slice

Develop an original SVG wordmark and inspect it at navigation size and in one color. Apply the chosen identity to the storefront and a live style guide using shared CSS variables, components, and assets. Keep the size selector and temporary demo bag working.

Propose two truthful Cialdini applications. For example, a freely available outfit-planning aid could offer useful value through reciprocity. A consistency application would require a voluntary prior choice and a relevant next step; mandatory size selection alone is insufficient. Select mechanisms because they help this visitor. Do not manufacture testimonials, scarcity, authority, or sales figures.

**Reviewable output:** a functioning product page, its matching guide, and a brief explanation of each persuasion element’s mechanism and factual basis.

## 5. Check behavior and meaning

Run the storefront project’s prepared checks when that implementation exists. Confirm that a valid selected size adds to the demo bag and that adding without a size gives useful feedback without increasing its count. Inspect the actual render, shared identity, keyboard use, and a narrow viewport.

Then gather a real person’s first impression and observations. Automated checks can establish their assertions; they cannot establish demand, brand fit, factual truth, complete accessibility, or someone’s understanding.

**Reviewable output:** real command results, screenshots or live links, observed issues, and revisions. Keep unperformed checks and missing observations explicitly pending.

## 6. Keep the decision and review the result

Record agreed choices and actual evidence in the implementation project’s specification. Use an issue and feature branch for its first branding slice, then review the checked change in a pull request. Keep the reference clone local and ignored. The separate VitePress site can continue to hold research, alternatives, and open decisions.

If the source template’s learner workflow is used, review its AI-drafted learning excerpts with the learner before publishing them. That workflow belongs to the student implementation; this planning site does not create or certify learner evidence.

**Reviewable output:** a concise decision record, the reviewed implementation, and its verified deployment link when published. Select one subsequent improvement based on what review revealed.
