# Plain White Tee Studio

This directory is an independent Git repository for the VitePress research and review site. Its remote is `git@github.com:kaw393939/plain-white-tee-studio.git` and its Pages base is `/plain-white-tee-studio/`.

Check the current directory and Git remote before making changes. The parent directory belongs to **AI Career Atlas** (`kaw393939/ai-career-research`); do not replace its files, change its remote, or publish T-shirt content to it.

- Run this site's commands from this directory: `npm ci`, `npm run dev`, `npm run check`.
- Keep local reference clones and downloaded working material in ignored `references/` directories. Never stage nested repositories or dependencies.
- Preserve sources, checked dates, price/pack/variant distinctions, and the difference between brand statements and independently verified facts.
- Brand territories and audience cards remain hypotheses until an actual choice or observation is recorded. Do not invent customer research, learner decisions, or product facts.
- This site is the planning companion. The source storefront and its learner workflow are separate future implementation work.
